# Application composition

This directory is the Next.js delivery layer and composition root for the
controlled Alpha. It may connect approved modules and platform adapters, but it
must not become the owner of reusable Business, authority, or economic policy.

Route folders and UI components do not define product-architecture responsibilities,
service boundaries, or Business authority. The current fixture-driven dashboard is
verified regression output and will be generalized only through REV2 proof.
